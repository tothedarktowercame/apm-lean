## Evidence notes

### t02A05 — false (normalisation of `μH[2]`)
- Definition: `apm_t02a05_outwardSphereIntegral omega c := ∫ q : Metric.sphere c 1, apm_t02a05_orientedCoefficient omega c q ∂μH[2]`.
- The integrand is the right one. With F = ((x−1)³, (y−2)³, z−3) the vector field of ω, and P the orthogonal projection onto Tₚ = n^⊥, we have Peᵢ×Peⱼ = det(eᵢ,eⱼ,n)·n, so Pe₁×Pe₂ = n₀n, Pe₀×Pe₂ = −n₁n and Pe₀×Pe₁ = n₂n. Then `orientedCoefficient` = n₀(F·n₀n) − n₁(F·(−n₁n)) + n₂(F·n₂n) = F·n, the outward flux density. The orientation is correct.
- The measure is not surface area. Mathlib: `def hausdorffMeasure (d : ℝ) : Measure X := mkMetric fun r => r ^ d`. This is Σ diam^d with no ω_d/2^d normalising constant. `hausdorffMeasure_pi_real` says `μH[card ι] = volume` only on `ι → ℝ` with the sup norm, where a set of diameter r fits in a cube of volume rᵈ. On Euclidean ℝ² the isodiametric inequality gives μH[2] = (2²/ω₂)·λ² = (4/π)·λ². Mathlib records the gap itself: `Mathlib/Geometry/Euclidean/Volume/Measure.lean` defines `μHE[d] := addHaarScalarFactor volume μH[d] • μH[d]` ("scaled to agree with Lebesgue measure"), and its `proof_wanted` identifies the factor as vol(Euclidean ball)/vol(sup ball) = π/4 for d = 2. The sphere subtype carries the induced metric, so `μH[2]` on it is the ambient unnormalised measure, which equals (4/π)·σ on this C¹ surface.
- Value: by the divergence theorem, ∫_S F·n dσ = ∫_B (3(x−1)² + 3(y−2)² + 1) = 44π/15 + 4π((c₀−1)²+(c₁−2)²), which is the bridge's formula. The encoded integral is (4/π) times this: 176/15 + 16((c₀−1)²+(c₁−2)²).
- Counterexample: c = (1,2,0). The right side of the iff holds, but the integral is 176/15 ≈ 11.73 ≠ 44π/15 ≈ 9.22. The first conjunct (44π/15 ≤ integral) is true, since 176/15 > 44π/15, but only by accident. `apm_t02A05_bridge_1` (sorry) is also false as stated.
- Faithful fix (either one): (1) replace `∂μH[2]` with `∂μHE[2]`, which is already in the pinned Mathlib and normalised to agree with area. The constants 44π/15 and 4π then become correct. (2) Keep `μH[2]` and change the constants to 176/15 and 16, though that bakes in an artefact of Mathlib's normalisation. Option (1) is the faithful reading of "∫_S ω". This is the same defect as t95J05 in open-grades-1.

### t98A02 — stronger (true as frozen)
- Frozen: X₁, X₂ are T2, compact, path-connected, smooth (`IsManifold 𝓘(ℝ,ℝ⁴) ⊤`), with H₄ ≅ ℤ. φᵢ : closedBall(0,1) → Xᵢ are only `Topology.IsEmbedding`. Y is the quotient of the two copies of Xᵢ ∖ φᵢ(open ball), with φ₁(s) ~ φ₂(s) for s ∈ S³. The claims are H₀ ≅ ℤ; Hₖ(Y) ≅ Hₖ(X₁)×Hₖ(X₂) for 1 ≤ k ≤ 3; H₄ ≅ ℤ; Hₖ = 0 for k ≥ 5.
- Relation to the source: the source says "you may assume φᵢ(D⁴) is a 4-simplex in the triangulation", which is permission to assume tameness, not part of the claim. The frozen statement covers every topological embedding, including wild ones whose exterior Xᵢ' is not a manifold with boundary near the sphere. That is more than asked, so the grade is **stronger**, provided it is true.
- Why it is true for wild balls, without taming:
  1. By invariance of domain, φ(open ball) is open, so X' := X ∖ φ(open ball) is closed. U := X ∖ φ(closed ½-ball) is open, and it deformation-retracts onto X' by the radial retraction of φ(annulus) (pasting along the closed sets X' and φ(½ ≤ |u| ≤ 1)). The collar needed here lies *inside* the ball, where it always exists. Mayer–Vietoris on X = U ∪ φ(open ball), with intersection ≃ S³, and orientability (H₄(X) ≅ ℤ makes H₄(X) → H₃(S³) an isomorphism) give: X' path-connected, Hₖ(X') ≅ Hₖ(X) for 1 ≤ k ≤ 3, H₄(X') = 0, Hₖ(X') = 0 for k ≥ 5 (Hₖ(X) = 0 for k > 4), and H₃(S³) → H₃(X') is zero.
  2. In Y the collars are gone, so Mayer–Vietoris on Y = X₁' ∪_{S³} X₂' needs S³ ⊂ Xᵢ' to be a cofibration. Borsuk's theorem gives this: if M = A ∪ B with A, B closed and M, A∩B ANRs, then A and B are ANRs. The proof is short: extend id_{A∩B} to a retraction ρ of a closed neighbourhood W of A∩B in B; then id_A ∪ ρ retracts the neighbourhood A ∪ W of A in M onto A. Apply it with M = X, A = X', B = φ(D⁴), A∩B = S³. So each Xᵢ' is a compact metric ANR, and closed ANR pairs have the homotopy extension property. Mayer–Vietoris then applies to the adjunction space Y.
  3. The Y sequence with the facts from step 1 gives exactly the frozen answer: H₁, H₂ split since H₁(S³) = H₂(S³) = 0; H₃ splits since H₃(S³) → H₃(Xᵢ') is 0; H₄(Y) ≅ H₃(S³) ≅ ℤ; higher groups vanish; H₀ ≅ ℤ.
  This is 1930s retract theory, not crumpled-cube taming. The statement's truth is not open.
- Smoothness does not narrow the statement: in dimension 4, triangulable = PL (vertex links are simply-connected homology 3-spheres, hence S³) = smooth, so the source's triangulated manifolds are exactly the smoothable ones.
- PRELIM-DEFECT (mild, as before): "connected oriented 4-manifolds" omits "closed". Compactness is required by the supplied fact H₄ ≅ ℤ and by the answer, and the header states the repair.
- Grade change from the registry's `faithful`: the earlier row already flagged "φᵢ arbitrary topological embeddings, not the tame simplex the source allows". Since the generalised claim is true, the accurate label is `stronger`. It is acceptable for the registry either way: nothing false or vacuous.

### t95J03 — narrower (S² dropped; still true)
- `T95J03SurfaceSpace (.orientable g) = TopCat.of (Surface true g)`. `ConstructionTargets.Surfaces.SurfaceRel true 0 x y` is `∃ j < 0, …`, which is empty, so `Surface true 0` is the quotient of the closed disk by equality: the disk itself. The same holds for `Surface false 0`. For g ≥ 1 the words are correct: `.orientable 1` is the torus (a b a⁻¹ b⁻¹), `.nonorientable 1` is RP² (antipodal boundary), and `.nonorientable 2` is the Klein bottle (aabb). So S² is not represented anywhere in the index type.
- Truth: for F = disk, any k-fold covering of the simply connected, locally path-connected disk is trivial, giving k disjoint closed disks. These have boundary points with no ℝ²-neighbourhood, while every cover of the Klein bottle is a boundaryless surface, so they are never homeomorphic. The disk is therefore not in the LHS, and the RHS never contains `.orientable 0` or `.nonorientable 0`. Covers are not required to be connected (`T95J03IsKFoldCover` only fixes fibre cardinality k), but this does not change the answer. Components have χ = dᵢ·χ(F), so χ(F) ≠ 0 is excluded. For odd k, some component of a Klein-bottle cover has odd degree and is nonorientable, which rules out the torus. The equality as encoded is true.
- Fidelity: the problem asks to describe S_k over all (closed) surfaces. S² ∉ S_k (all its k-fold covers are k copies of S², with χ = 2k ≠ 0) is a genuine, if easy, part of the classification, and the encoding never states it. The slot where S² belongs holds the disk, which is excluded for a different, trivial reason. So the statement is narrower by exactly the S² case. It is not wrong.
- Fix: define `T95J03SurfaceSpace (.orientable 0)` as a genuine S² (for example `Metric.sphere (0 : EuclideanSpace ℝ (Fin 3)) 1`) and leave the rest alone. `.nonorientable 0` is a meaningless index. It is harmless because it is excluded on both sides, but could be removed.

### t00A03 — faithful (free homotopy vs annulus)
- `apm_t00a03_parallel c d := ∃ (e : Circle ≃ₜ Circle) (H : ℝ × Circle → F), ContinuousOn H (Icc 0 1 ×ˢ univ) ∧ (∀ z, H (0, z) = c z) ∧ (∀ z, H (1, z) = d (e z))`. This is a free homotopy from c to a reparametrisation of d, which allows orientation reversal. That matches the unoriented "co-bound an annulus".
- Where it is used: (i) `hnonparallel : ∀ i j, i ≠ j → ¬parallel (curves i) (curves j)`, alongside `hdisjoint` for the same i ≠ j; (ii) `hmax`, which applies only to c with `∀ i, disjoint c (curves i)`. So the relation is only ever evaluated on pairs of disjoint, embedded, essential curves.
- For disjoint essential simple closed curves on a closed orientable surface, freely homotopic ⟺ they co-bound an embedded annulus (Epstein 1966, "Curves on 2-manifolds and isotopies", Lemma 2.4; see also Farb–Margalit, *Primer*, ch. 1). This holds for topological embeddings, via Schoenflies. So swapping "co-bound an annulus" for free homotopy changes neither "nonparallel" nor "maximal" on the curves where the statement uses them. Likewise `¬nullHomotopic` ⟺ "does not bound a disk" for simple closed curves (Epstein).
- Remaining encoding checks: `apm_t00a03_hasGenus g F` (H₀ ≅ ℤ, H₁ ≅ ℤ^{2g}, H₂ ≅ ℤ) together with smooth compact T2 path-connected pins F to the closed orientable genus-g surface. The pants model `apm_t00a03_Pants` uses the sup norm on ℝ×ℝ: an open square minus two disjoint closed squares inside it. That is homeomorphic to the open three-holed sphere, which is the right type for a component of the complement of the curves. `n = 3 * g - 3` is the repaired count, and every maximal family is a pants decomposition with 3g−3 curves. Both conjuncts are true and match the problem.
- PRELIM-DEFECT: "3g−g" is a typo for 3g−3 (Euler characteristic 2−2g = −(number of pants), and 3P = 2n). The header states the repair, and the source solution confirms it.
