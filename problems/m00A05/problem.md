## Problem Statement

Raw TeX source:

```tex
Consider the first-order differential equation $u'(t)+u(t)=\cos(u(t))$
posed as an initial value problem for $t>0$ with initial condition
$u(0)=u_0$
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item Use the contraction mapping theorem to show that there is
exactly one solution $u$ satisfying these conditions that corresponds
to any given $u_0\in \R$.
%------------------------------------------------------------------*
\item Prove that there is a number $\xi$ such that $\lim_{t\rightarrow
\infty}u(t)=\xi$ for any solution $u$ of the differential equation,
independent of the value $u_0$.
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
```
