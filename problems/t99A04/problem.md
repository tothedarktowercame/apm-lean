# t99A04

## Bundle Overview

This directory is the canonical APM problem bundle for this problem.

## Problem Statement

Raw TeX source:

```tex
Let $X$ be a connected, oriented, compact $2$-manifold and let
$f:\Son\rightarrow X$ be a smooth embedding of a circle. We say that
$f$ is \emph{separating} if $X\setminus f(\Son)$ is disconnected;
otherwise $f$ in \emph{nonseparating}.
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item For closed $1$-forms $\eta$ on $F$ what are the possible values of 
$\int_{\Son} f^*\eta$ if $f$ is separating? Why?
%------------------------------------------------------------------*
\item Does the answer remain the same if $f$ is nonseparating? Prove
or find a counterexample.
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
```
