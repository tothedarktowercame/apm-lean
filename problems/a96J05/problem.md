## Problem Statement

Raw TeX source:

```tex
Let $1\leq p<q\leq \infty$ and write $L^p=L^p([0,1],\nu)$ and
$L^q=L^q([0,1],\nu)$, where $\nu$ is Lebesgue measure restricted to
$[0,1]$. Define $X=\{g+h\pipe g\in L^p \text{\ and\ } h\in L^q\}$, and
define $\|\cdot \|_X:X\rightarrow [0,\infty)$ by
$\|f\|_X=\inf\{\|g\|_p+\|h\|_q\pipe g\in L^p, h\in L^q, f=g+h\}$.
Prove that $X$ is a vector space, $\|\cdot \|_X$ is a norm on $X$ and
$X$ is complete with respect to this norm.
```
