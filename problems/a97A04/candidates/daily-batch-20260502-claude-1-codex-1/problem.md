## Statement

```

space $(X,\Sigma,\mu)$. Suppose that $\forall x\in X:(f_n(x))_{n\in
\N}$ is a bounded sequence. Let $E=\{x\in X \pipe (f_n(x))_{n\in \N}
\text{\ converges}\}$. Show that $E\in \Sigma$.
```
