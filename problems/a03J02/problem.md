## Problem Statement

Raw TeX source:

```tex
Let $f:\Rn\rightarrow \Rn$ be a polynomial map, \ie\ each component
$f_i$ is in $\R[x_1,\ldots,x_n]$. Show that every set $E\subset \Rn$
with Lebesgue measure zero has the property that $f(E)$ has measure
zero.
```
