Informal proof

**Why it's hard:** L^p functions are only defined a.e. and need not be continuous, so showing the average f_h is continuous in t requires a soft argument (continuity of integral with respect to its limits) rather than a pointwise calculation. The bound is a textbook Hölder application but requires care about extending f outside [0,1].

**The key insight:** The averaging operator f_h(t) is essentially the convolution of f (extended by zero outside [0,1]) with the indicator (1/(2h))·1_{[-h,h]}, which is in L^q where q is the Hölder conjugate of p. Continuity of f_h in t follows from continuity of integration with respect to translation in L^p (or directly from the dominated convergence theorem applied to ∫_{t-h}^{t+h} f). The L^∞ bound is a single application of Hölder's inequality.

**Proof:**

Extend f by 0 outside [0,1], denoting the extension still by f, so f ∈ L^p(ℝ) with ‖f‖_{L^p(ℝ)} = ‖f‖_{L^p([0,1])}.

*Step 1: Pointwise bound via Hölder.*

For any t ∈ [0,1]:
$$f_h(t) = \frac{1}{2h}\int_{t-h}^{t+h} f(x)\,dx = \frac{1}{2h}\int_\mathbb{R} f(x) \cdot \mathbf{1}_{[t-h, t+h]}(x)\,dx$$

Apply Hölder's inequality with exponents p and q = p/(p-1) (with q = ∞ if p = 1):

$$|f_h(t)| \leq \frac{1}{2h}\|f\|_p \cdot \|\mathbf{1}_{[t-h, t+h]}\|_q$$

Compute the L^q norm of the indicator:
- If 1 < p < ∞: ‖1_{[t-h,t+h]}‖_q = (2h)^{1/q} = (2h)^{1 - 1/p}
- If p = 1: q = ∞, ‖1_{[t-h,t+h]}‖_∞ = 1 = (2h)^0 = (2h)^{1 - 1/p}

In both cases:
$$|f_h(t)| \leq \frac{1}{2h} \cdot \|f\|_p \cdot (2h)^{1 - 1/p} = (2h)^{-1/p} \|f\|_p$$

This establishes the bound.

*Step 2: Continuity of f_h.*

Fix t_0 ∈ [0,1] and a sequence t_n → t_0 in [0,1]. We want f_h(t_n) → f_h(t_0).

Write:
$$2h \cdot (f_h(t_n) - f_h(t_0)) = \int_{t_n - h}^{t_n + h} f - \int_{t_0 - h}^{t_0 + h} f = \int_\mathbb{R} f \cdot (\mathbf{1}_{[t_n - h, t_n + h]} - \mathbf{1}_{[t_0 - h, t_0 + h]})\,dx$$

Apply Hölder again:
$$2h \cdot |f_h(t_n) - f_h(t_0)| \leq \|f\|_p \cdot \|\mathbf{1}_{[t_n-h, t_n+h]} - \mathbf{1}_{[t_0-h, t_0+h]}\|_q$$

The symmetric difference of [t_n - h, t_n + h] and [t_0 - h, t_0 + h] has measure at most 2|t_n - t_0|. So:

- If 1 < p < ∞: ‖1_A - 1_B‖_q ≤ (m(A △ B))^{1/q} ≤ (2|t_n - t_0|)^{1/q} → 0.
- If p = 1: the indicator difference is bounded by 1 in L^∞, but the calculation needs the dominated convergence theorem instead. Specifically, for p = 1, write f_h(t) = (1/(2h))(F(t+h) - F(t-h)) where F(s) = ∫_{-∞}^s f(x)dx is absolutely continuous (since f ∈ L¹), hence continuous. So f_h is continuous.

Combining the cases, f_h(t_n) → f_h(t_0). Since t_0 was arbitrary, f_h is continuous on [0,1]. ∎

**What connects:** This is the basic boundedness and continuity result for the averaging operator, which is the simplest mollifier. The estimate |f_h(t)| ≤ (2h)^{-1/p} ‖f‖_p shows that smoothing by averaging at scale h costs a factor of (2h)^{-1/p} in L^∞ norm — this is sharp and matches the bound from Young's convolution inequality with kernel (1/(2h))·1_{[-h,h]}. The continuity argument generalizes: convolution f * φ of an L^p function with an L^q function (Hölder conjugates) is continuous. The same technique underlies the Lebesgue differentiation theorem (showing f_h(t) → f(t) a.e.) and the construction of mollifier approximations to the identity.
