## Problem Statement

Raw TeX source:

```tex
In this problem, all groups are abelian groups (which we can also
think of as $\Z$ modules).
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item Suppose $B\rightarrow C\rightarrow 0$ is an exact sequence of
abelian groups. If $M$ is an abelian group, show that $B \otimes_{\Z}
M\rightarrow C \otimes_{\Z}M\rightarrow 0$ is exact.
%------------------------------------------------------------------*
\item Describe (with proof) all abelian group homomorphisms
$f:\Z\rightarrow \Z$.
%------------------------------------------------------------------*
\item Show that $\Z\otimes_{\Z}\Z/2\Z\cong \Z/2\Z$.
%------------------------------------------------------------------*
\item Prove or disprove: if $f:\Z\rightarrow \Z$ is such that
$0\rightarrow \Z\rightarrow \Z$ is exact, then the induced
homomorphism $0\rightarrow \Z\otimes_{\Z}\Z/2\Z\rightarrow
\Z\otimes_{\Z}\Z/2\Z$ is exact.
%------------------------------------------------------------------*
\item Define an abelian group $M$ to be \emph{flat} if all exact sequences
$0\rightarrow B\rightarrow C$ the induced sequence $0\rightarrow
B\otimes_{\Z}M\rightarrow C\otimes_{\Z}M$ is exact.  Which cyclic
groups are flat? Give a proof if possible, but educated guessing is
encouraged.
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
```
