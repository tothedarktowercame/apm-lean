## Problem Statement

Raw TeX source:

```tex
Let $\Omega\subset \C$ be open, simply connected, and not empty. Show
that if $f:\Omega\rightarrow \C$ is holomorphic and has no zeros in
$\Omega$ then there exists a holomorphic function $g:\Omega\rightarrow
\C$ such that $f(z)=\exp\{g(z)\}$ at each point $z\in \Omega$.
```
