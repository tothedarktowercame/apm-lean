## Problem Statement

Raw TeX source:

```tex
Let $f\in L^1((0,\infty))$ and then define
$h(x)=\int_0^{\infty}f(y)/(x+y)dy$ for $x>0$. Show that $h$ is
infinitely differentiable on $(0,\infty)$. Prove that $h'\in
L^1([a,\infty))$ for each $a>0$. What happens if we try to set $a=0$?
```
