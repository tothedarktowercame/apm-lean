## Problem Statement

Raw TeX source:

```tex
Let $V$ be a real Hilbert space and let $f\in V'$ be a continuous
linear functional on $V$. Define the quadratic function
$\varphi:V\rightarrow \R$ by $\varphi(v)=\frac{1}{2}\|v\|^2-f(v)$ for
$v\in V$ where the norm is that of $V$.
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item Show that $\varphi$ is bounded below and that there is a unique
point $u\in V$ for which $\varphi$ realizes its minimum value, \ie\
$v\in V$ and $V\neq u\Rightarrow \varphi(u)<\varphi(v)$.
%------------------------------------------------------------------*
\item Show that at the minimum point $u$ we have $\forall v\in
V:(u,v)_V=f(v)$.
%------------------------------------------------------------------*
\item Use appropriate choices of $\varphi$ and $V$ to show that there
are weak solutions to the boundary value problem $-\triangle u+u=F$ in
$\Omega$ with $u=0$ on $\partial \Omega$ where $\Omega$ is a bounded
domain in $\Rn$. Specify carefully the function classes used and
explain what is meant here by a weak solution.
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
```
