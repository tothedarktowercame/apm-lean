## Problem Statement

Raw TeX source:

```tex
Let $\Delta=\{z\pipe|z|<1\}$ and let $f:\bar{\Delta}\rightarrow \C$ be
a continuous function that is analytic in $\Delta$ satisfies
$|f(z)|\leq 1$ for all $z$ in $\partial \Delta$ and has no fixed
points on $\partial \Delta$, \ie\ $f(z)\neq z$ holds for all $z$
belonging to $\partial \Delta$. Verify that $f$ has exactly one fixed
point in $\Delta$.
```
