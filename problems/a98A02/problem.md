## Problem Statement

Raw TeX source:

```tex
Let $(g_k)$ be a sequence of Lebesgue measurable functions defined on
$[0,1]$ so that for some $M<\infty$ and all $n,m$ we have
$|g_n(x)|\leq M$ for all $x\in [0,1]$ and
$\int_0^1g_n(x)g_m(x)dx=\delta_{n,m}$.

Show that for any $f$ in $L^1$ $\lim_{n\rightarrow \infty}\int_0^1
fg_n dx=0$. Hint: start with $f$ in $L^2$.
```
