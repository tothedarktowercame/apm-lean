## Problem Statement

Raw TeX source:

```tex
Show that for $y\in \Rtw$ fixed, $\frac{1}{2\pi}\ln|x-y|$ is locally
integrable in $\Rtw$, \ie\ it is a function in
$L_{1,\mathrm{loc}}(\Rtw)$, and show that it is a fundamental solution
of $\triangle u=\delta_y$ where $\triangle = \partial_{x_1}^2+=
\partial_{x_2}^2$ is the Laplace operator.
```
