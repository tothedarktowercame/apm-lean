## Problem Statement

Raw TeX source:

```tex
For $f\in L^2(\R)$ and $t>0$, consider the function $u(x,t)=(1/4\pi
t)^{n/2}\int_{\Rn}e^{-(x-y)^2/4t}f(y)dy$.

Show that
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item $u$ is smooth in the variable $x$.
%------------------------------------------------------------------*
\item For fixed $t$, $u$ satisfies 
$\|u\|_{L^2(\Rn)}\leq \|f\|_{L^2(\Rn)}$.
%------------------------------------------------------------------*
\item $\lim_{t\rightarrow 0^+}u(x,t)=f(x)$ in $L^2(\Rn)$.
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
```
