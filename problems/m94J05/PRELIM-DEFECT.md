# Prelim defect

Unrestricted uniqueness as printed is false. For f = 0, x = 0 is a solution. With q = 1/t and z(q) = x(1/q) the equation becomes z'' = z²/q² on [1/2, 1] with z(1/2) = z(1) = 0. Shooting from z(1/2) = 0 with z'(1/2) = -a gives z < 0 on (1/2, 1] for small a > 0, while large a forces a zero before q = 1. At a* = sup{a : z < 0 on (1/2, 1]} the solution has z(1) = 0 and is not zero. This second solution is a shooting argument, not formalised here.

What it was trying to say, given the printed hint x = L⁻¹F(x), is the contraction statement: for small f there is a solution, unique among solutions of small sup norm. The registered statement says exactly that.
