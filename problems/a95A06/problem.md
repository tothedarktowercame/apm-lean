## Problem Statement

Raw TeX source:

```tex
Let $\Delta=\{z\pipe |z|<1\}$. Define a function $f$ on the closed
disk $\bar{\Delta}$ by
$f(z)=\sum_{n=1}^{\infty}z^{n!}/n!$. Demonstrate that
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item $f$ is a continuous function, analytic in $\Delta$;
%------------------------------------------------------------------*
\item $f$ has the property that there is no open set $U$ that properly
contains $\Delta$ and has an analytic function $F$ defined on it with
$F(z)=f(z)$ for every $z\in \Delta$. 
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
Hint: for part (b), consider $\lim_{r\rightarrow 1^-}|f'(re^{2\pi
i\theta})|$ when $\theta$ is a rational number.
```
