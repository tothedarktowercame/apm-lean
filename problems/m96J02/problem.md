## Problem Statement

Raw TeX source:

```tex
Let $g$ be a continuous real-valued function on $\Rtw$ and let
$\alpha,\beta\in \R$. Prove that there is a $T>0$ such that if $x\in
C^2([0,T])$ solves the initial value problem $x''(t)=g(t,x(t))$,
($x(0)=\alpha,x'(0)=\beta)$) and $y\in C[(0,T)]$ satisfies the
Volterra integral equation
$y(t)=\int_{0}^t(t-s)g(s,y(s))dz+\alpha+\beta t$, then $x=y$.
```
