# APM t02A08: Realizing every oriented intersection number with a degree-n sphere in S¹ × S²

## Why It's Hard

The task is to hit **every** integer as an oriented intersection number, so it is really a *realization*
problem: show that the intersection pairing on `Y = S^1\times S^2` is surjective onto `\mathbb Z`, by
building an explicit family of maps `f_n`. Two things must be handled with care:

- **Get the dimensions right.** The oriented intersection number `I_Y(f, Z)` of a map `f : X \to Y` with a
  closed submanifold `Z\subseteq Y` is a *signed count of points*, defined only when `\dim X + \dim Z = \dim
  Y`. Here `X = S^2` (`\dim 2`) and `Y = S^1\times S^2` (`\dim 3`), so the partner must have **dimension
  `1`**. The fiber sphere `\{p\}\times S^2` is `2`-dimensional — it is the homology class the sphere `f`
  will *wrap*, and its Poincaré-dual partner, the actual `1`-dimensional intersection target, is the base
  circle `Z = S^1\times\{q\}`. Pairing `f(S^2)` against `\{p\}\times S^2` directly would be two surfaces in
  a `3`-manifold, giving a *curve*, not a number; recognizing this is the crux.
- **Compute the intersection number honestly.** One must produce transversality and add up *signs*, not just
  count points. The key is that the signed count equals the **degree** of a map `S^2\to S^2`, and degree-`n`
  self-maps of `S^2` exist for every `n`.

## The Key Insight

`H_2(S^1\times S^2) = \mathbb Z`, generated by the fiber `\sigma = [\{p\}\times S^2]`, and `H_1 = \mathbb Z`,
generated by the base circle `c = [S^1\times\{q\}]`; the two meet transversally in **one** point, so `\sigma
\cdot c = 1`. Therefore a sphere `f : S^2\to Y` with `f_*[S^2] = n\,\sigma` has intersection number `n` with
the circle `S^1\times\{q\}`. Such a sphere is built by mapping into a single fiber by a **degree-`n`** map:
$$
f_n : S^2 \to S^1\times S^2, \qquad f_n(x) = \big(p_0,\ g_n(x)\big), \quad \deg g_n = n .
$$
Then `f_n^{-1}(S^1\times\{q\}) = g_n^{-1}(q)`, whose signed count is `\deg g_n = n`, so `I_Y(f_n, S^1\times\{q\}) = n`.

## Complete Proof

Let `Y = S^1\times S^2`, with projections `\pi_1 : Y\to S^1`, `\pi_2 : Y\to S^2`, and fix orientations so
that `Y` carries the product orientation `(\text{or}\,S^1)\oplus(\text{or}\,S^2)`. Fix `p_0\in S^1` and a
point `q\in S^2`.

### The intersection target and the homology pairing

The oriented intersection number `I_Y(f, Z)` for `f : S^2\to Y` is defined (as a signed count of points)
only when `\dim S^2 + \dim Z = \dim Y`, i.e. `\dim Z = 1`. The natural `1`-dimensional submanifold is the
**base circle**
$$
Z := S^1\times\{q\} \subset Y, \qquad \dim Z = 1 .
$$
This is exactly the Poincaré-dual partner of the fiber sphere `\{p\}\times S^2`: in the homology of `Y`,
$$
H_2(Y) = \mathbb Z\cdot\sigma,\quad \sigma = [\{p\}\times S^2]; \qquad H_1(Y) = \mathbb Z\cdot c,\quad c = [S^1\times\{q\}],
$$
and `\{p\}\times S^2` meets `S^1\times\{q\}` in the single point `(p,q)`, transversally, so the intersection
pairing satisfies `\sigma\cdot c = 1`. Consequently, for any `f : S^2\to Y`,
$$
I_Y(f, Z) = \big(f_*[S^2]\big)\cdot c, \qquad\text{and if } f_*[S^2] = n\,\sigma \text{ then } I_Y(f,Z) = n(\sigma\cdot c) = n. \tag{$\dagger$}
$$
So it suffices to construct, for each `n\in\mathbb Z`, a sphere `f_n` with `f_{n*}[S^2] = n\,\sigma`.

### The construction

For each integer `n`, choose a smooth map
$$
g_n : S^2 \to S^2, \qquad \deg g_n = n .
$$
These exist for every `n`: `g_0 = \text{const}`, `g_1 = \mathrm{id}`, `g_{-1} = ` a reflection
(orientation-reversing), and for `|n|\ge 2` an `n`-fold "pinch/branched" map (e.g. realize `S^2` as
`\mathbb{CP}^1` and take `z\mapsto z^n`, which has degree `n`). Define
$$
\boxed{\ f_n : S^2 \to Y = S^1\times S^2, \qquad f_n(x) = \big(p_0,\ g_n(x)\big).\ }
$$
This lands in the single fiber `\{p_0\}\times S^2`, and `f_{n*}[S^2] = (g_n)_*[S^2]` viewed in that fiber
`= n\,[S^2] = n\,\sigma`. By `(\dagger)`, `I_Y(f_n, Z) = n`. We now verify this by an explicit
transversality-and-sign computation.

### Detailed computation of the intersection number

**The preimage.** A point `f_n(x) = (p_0, g_n(x))` lies in `Z = S^1\times\{q\}` iff its second coordinate is
`q`:
$$
f_n^{-1}(Z) = \{x\in S^2 : g_n(x) = q\} = g_n^{-1}(q) .
$$
Choose `q` to be a **regular value** of `g_n` (possible by Sard's theorem). Then `g_n^{-1}(q) = \{x_1,\dots,x_m\}`
is a finite set.

**Transversality `f_n \pitchfork Z`.** At a point `x_i\in g_n^{-1}(q)`, with `y_i := f_n(x_i) = (p_0,q)`,
$$
T_{y_i}Y = T_{p_0}S^1 \oplus T_q S^2, \qquad T_{y_i}Z = T_{p_0}S^1 \oplus 0,
$$
$$
df_n\big(T_{x_i}S^2\big) = 0 \oplus dg_n\big(T_{x_i}S^2\big) = 0 \oplus T_q S^2,
$$
the last equality because `q` is a regular value (so `dg_n` is onto `T_qS^2`). Adding,
$$
df_n(T_{x_i}S^2) + T_{y_i}Z = (0\oplus T_qS^2) + (T_{p_0}S^1\oplus 0) = T_{p_0}S^1\oplus T_qS^2 = T_{y_i}Y,
$$
so `f_n` is transverse to `Z` at each `x_i` (and `\dim S^2 + \dim Z = 2+1 = 3 = \dim Y`, so the sum is
direct).

**Signs.** The local intersection sign at `x_i` is `+1` iff the orientation of
`df_n(T_{x_i}S^2)\oplus T_{y_i}Z` agrees with that of `T_{y_i}Y`. Now `T_{y_i}Z = T_{p_0}S^1` carries the
`S^1`-orientation, and `df_n(T_{x_i}S^2) = T_qS^2` is oriented by `dg_n`, i.e. with the **local degree**
`\deg_{x_i}(g_n) = \pm 1` relative to the `S^2`-orientation. Since `Y` is oriented by
`(\text{or}\,S^1)\oplus(\text{or}\,S^2)`, comparing
$$
\underbrace{df_n(T_{x_i}S^2)}_{\pm(\text{or}\,S^2)} \oplus \underbrace{T_{y_i}Z}_{\text{or}\,S^1}
\quad\text{against}\quad \underbrace{T_{p_0}S^1}_{\text{or}\,S^1}\oplus\underbrace{T_qS^2}_{\text{or}\,S^2}
$$
(a reordering of the two oriented summands, which contributes a fixed sign independent of `i`) shows the
intersection sign at `x_i` equals the **local degree** `\deg_{x_i}(g_n)` up to a global sign convention.
With orientations fixed once and for all,
$$
\operatorname{sign}(x_i) = \deg_{x_i}(g_n).
$$

**Summation.** Therefore
$$
I_Y(f_n, Z) = \sum_{x_i\in g_n^{-1}(q)} \operatorname{sign}(x_i) = \sum_{x_i\in g_n^{-1}(q)} \deg_{x_i}(g_n) = \deg(g_n) = n,
$$
the middle-to-right equality being the definition of the degree of `g_n` as the signed count of preimages of
a regular value `q`. This holds for every integer `n`, completing the construction. ∎

**Remark.** The fiber sphere `\{p\}\times S^2` named in the problem is precisely the generator `\sigma` of
`H_2(Y)` that `f_n` wraps `n` times (`f_{n*}[S^2] = n\sigma`); its *intersection partner* — the
`1`-dimensional class needed so that the count is `0`-dimensional — is the base circle `S^1\times\{q\}`, with
`\sigma\cdot c = 1`. The whole problem is the statement that the intersection form `H_2(Y)\times H_1(Y)\to
\mathbb Z` of `S^1\times S^2` is the unimodular pairing `\langle 1\rangle`, so it is *onto* `\mathbb Z`, and
degree-`n` maps into a fiber realize each value. (Dually, if one instead intersects loops `\gamma_n :
S^1\to Y`, `\gamma_n(\theta) = (e^{2\pi i n\theta}, q_0)`, against the fiber `\{p\}\times S^2`, the same
pairing gives `I_Y(\gamma_n, \{p\}\times S^2) = n` — the winding number around `S^1` — the mirror image of
the construction above.)
