## Problem Statement

Raw TeX source:

```tex
Let $D\subset \C$ be an open simply connected set and
$\gamma:[0,1]\rightarrow D$ a simple closed rectifiable path in $D$.
Write $\Gamma=\{\gamma(t) \pipe 0\leq t\leq 1\}$ for the image of $\gamma$
in $D$. Suppose that $\{f_n\}_{n=1}^{\infty}$ is a sequence of
functions that are analytic on $D$ and that converge uniformly to $g$
on compact subsets of $D$. Assume that $g(z)\neq 0$ for $z\in
\Gamma$. Show that there is an integer $N$ such that $n\geq N$ implies
$f_n(z)$ and $g(z)$ have the same number of zeros inside $\Gamma$.
```
