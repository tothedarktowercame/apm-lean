# APM t94A01: The metric ρ(f,g)=Σ2⁻ⁱ|fᵢ−gᵢ| induces the product topology on [0,1]^ℕ

## Why It's Hard

Two topologies on the same set are equal exactly when **each is finer than the other**, so the proof
necessarily has two halves pulling in opposite directions, and the tension between them is the whole point:

- The **product topology** is generated by *finite-coordinate* boxes — a basic open set restricts only
  finitely many coordinates and leaves all the rest free. It is "blind" to any single far-out coordinate.
- The **metric** `\rho(f,g)=\sum 2^{-i}|f_i-g_i|` involves *all* coordinates at once. The danger is that this
  could make the metric topology strictly *finer* (like the box or uniform topology, which on an infinite
  product genuinely differ from the product topology). What rescues it is the **geometric decay** `2^{-i}`:
  the tail `\sum_{i>N}2^{-i}=2^{-N}\to0` is negligible, so only finitely many coordinates "matter up to
  `\epsilon`," which is precisely the product-topology flavor.

The two technical hurdles are: (i) fitting a *finite*-coordinate box inside an arbitrary `\rho`-ball (uses
the decaying tail), and (ii) showing each coordinate is metrically continuous (uses `|f_i-g_i|\le
2^i\rho(f,g)`). Choosing the box's width `\delta` and cutoff `N` to beat `\epsilon` is the crux.

## The Key Insight

Show each topology contains the other:

- **Product `\subseteq` metric:** each projection `\pi_i` is `\rho`-Lipschitz (`|f_i-g_i|\le 2^i\rho(f,g)`),
  so all projections are `\rho`-continuous; since the product topology is the *coarsest* making projections
  continuous, it is contained in the metric topology.
- **Metric `\subseteq` product:** every `\rho`-ball `B_\rho(f,\epsilon)` contains a finite-coordinate box
  around `f`. Pick `N` with `2^{-N}<\epsilon/2` (killing the tail) and `\delta=\epsilon/2`; the box
  `\{g:|g_i-f_i|<\delta\ \text{for}\ i\le N\}` satisfies `\rho(f,g)<\tfrac\epsilon2+\tfrac\epsilon2=\epsilon`,
  so it sits inside the ball. The decaying weights make this finite box suffice.

## Complete Proof

Let `X=\prod_{i\ge1}[0,1]`. First note `\rho` is a genuine metric: `\rho(f,g)=\sum_i 2^{-i}|f_i-g_i|\le
\sum_i 2^{-i} = 1<\infty` converges (terms bounded by `2^{-i}`), it is symmetric, vanishes iff every
`|f_i-g_i|=0` (i.e. `f=g`), and satisfies the triangle inequality term-by-term. Write `T_\rho` for the
metric topology and `T_\pi` for the product topology. We show `T_\rho = T_\pi` by proving both inclusions.

### Step 1: `T_\pi \subseteq T_\rho` (each projection is `\rho`-continuous)

For any fixed `i` and any `f,g\in X`, the `i`-th term alone is at most the whole sum:
$$
2^{-i}\,|f_i-g_i| \le \sum_{j\ge1} 2^{-j}|f_j-g_j| = \rho(f,g),
$$
so
$$
|\pi_i(f)-\pi_i(g)| = |f_i-g_i| \le 2^{i}\,\rho(f,g).
$$
Thus each projection `\pi_i : (X,\rho)\to[0,1]` is Lipschitz (constant `2^i`), hence `\rho`-continuous. The
product topology `T_\pi` is by definition the **coarsest** topology on `X` making all the `\pi_i`
continuous; since `T_\rho` is *a* topology making all `\pi_i` continuous, it must contain `T_\pi`. Hence
$$
T_\pi \subseteq T_\rho .
$$
(Equivalently: a subbasic product-open set `\pi_i^{-1}(V)`, `V\subseteq[0,1]` open, is `\rho`-open by
continuity of `\pi_i`; so all product-open sets are `\rho`-open.)

### Step 2: `T_\rho \subseteq T_\pi` (each `\rho`-ball contains a product-basic neighborhood)

It suffices to show: for every `f\in X` and `\epsilon>0`, there is a product-open set `U` with `f\in U
\subseteq B_\rho(f,\epsilon)`. Then each `\rho`-ball is a union of product-open sets (one around each of its
points), hence product-open, and so every `\rho`-open set is product-open.

**Choose the cutoff and width.** Since `\sum_{i>N}2^{-i}=2^{-N}\to0`, pick `N` with
$$
2^{-N} < \tfrac{\epsilon}{2},
$$
and set `\delta=\tfrac{\epsilon}{2}`. Define the **finite-coordinate box**
$$
U = \{\,g\in X : |g_i - f_i| < \delta \ \text{ for all } i=1,\dots,N\,\},
$$
which restricts only the first `N` coordinates, so it is a basic open set in the product topology, and
`f\in U`.

**The box fits in the ball.** For `g\in U`, split the sum at `N` and bound each part:
$$
\rho(f,g) = \underbrace{\sum_{i=1}^{N} 2^{-i}|f_i-g_i|}_{\text{small width}} + \underbrace{\sum_{i>N} 2^{-i}|f_i-g_i|}_{\text{small tail}} .
$$
For `i\le N`, `|f_i-g_i|<\delta`, so the first sum is `< \delta\sum_{i=1}^{N}2^{-i} < \delta\sum_{i=1}^{\infty}2^{-i}
= \delta = \tfrac{\epsilon}{2}`. For `i>N`, `|f_i-g_i|\le1` (both coordinates lie in `[0,1]`), so the second
sum is `\le \sum_{i>N}2^{-i} = 2^{-N} < \tfrac{\epsilon}{2}`. Therefore
$$
\rho(f,g) < \tfrac{\epsilon}{2} + \tfrac{\epsilon}{2} = \epsilon,
$$
i.e. `g\in B_\rho(f,\epsilon)`. Hence `f\in U\subseteq B_\rho(f,\epsilon)`, as required, and
$$
T_\rho \subseteq T_\pi .
$$

### Conclusion

From Steps 1 and 2, `T_\pi\subseteq T_\rho` and `T_\rho\subseteq T_\pi`, so
$$
\boxed{\ T_\rho = T_\pi\ }
$$
— the metric topology and the product topology on `X=[0,1]^{\mathbb N}` coincide. ∎

**Remark.** The geometric weights `2^{-i}` are doing the essential work, and one sees exactly how in each
direction: in Step 1 they give the finite Lipschitz constant `2^i` per coordinate (so coordinates are
metrically continuous), and in Step 2 their summable tail `\sum_{i>N}2^{-i}=2^{-N}` lets a *finitely*
constrained box approximate a ball — which is the defining feature of the product topology. This is why `X`
(the **Hilbert cube**) is metrizable with the product topology, even though general infinite products are
not: any summable sequence of positive weights `w_i` (with `\sum w_i<\infty`) on bounded factors yields a
metric `\sum w_i|f_i-g_i|` inducing the product topology. By contrast, the *uniform/box* metric
`\sup_i|f_i-g_i|` (constant weights) gives a strictly finer, non-product topology — the decay is exactly
what aligns the metric with Tychonoff's product topology.
