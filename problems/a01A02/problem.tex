Let $f:\Rn\rightarrow \R$ be a Lebesgue measurable function such that
$m\{x \pipe |f(x)|>\lambda\} \leq C\lambda^{-2}$ for some $\lambda>0$
(I think that is what this means). Prove that there is a constant
$C_1$ such that for any Borel set $E\subset \Rn$ of finite and
positive measure has the property that $\int_E|f(x)|dx \leq C_1
\sqrt{m(E)}$.
