## Problem Statement

Raw TeX source:

```tex
A function $f[0,1]\rightarrow \R$ is given to be absolutely
continuous.
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item State the definition of ``absolutely continuous''.
%------------------------------------------------------------------*
\item Show that for each $\epsilon>0$ there is a $\delta>0$ with
the property that $m^*[f(E)]\leq \epsilon$ whenever $E$ is a subset of
$[0,1]$ for which $m^*(E)\leq \delta$. Here $m^*$ denotes Lebesgue
outer measure and $f(E)=\{f(x)\pipe x\in E\}$. Hint: start with the
case in which $E$ is a finite union of non-overlapping intervals.
%------------------------------------------------------------------*
\item Prove that if $E$ is Lebesgue measurable subset of $[0,1]$, then 
$f(E)$ is also Lebesgue measurable. Hint: exploit the regularity of
Lebesgue measure.
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
```
