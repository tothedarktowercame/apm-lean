## Problem Statement

Raw TeX source:

```tex
If a function $f:[0,1]\rightarrow \R$ is square integrable with
respect to Lebesgue measure and satisfies $\int_0^1x^nf(x)dx=0$ for
$n=0,1,2,\ldots $ then $f(x)=0$ for almost every $x\in [0,1]$. Prove 
this.
```
