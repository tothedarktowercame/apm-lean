## Problem Statement

Raw TeX source:

```tex
Let $\varphi$ be a measurable function on $\Rn$ such that
$|\int_Q\varphi(x)dx| \leq \frac{M m(Q)}{1+m(Q)}$ for every
$n$-dimensional rectangle $Q$. Here $m$ denotes Lebesgue measure.
Show that if $f\in L^1(\Rn)$ and $k>0$ that 
$\lim_{k\rightarrow \infty}\int_{\Rn}\varphi(kx)f(x) dx=0.$
```
