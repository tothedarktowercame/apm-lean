## Problem Statement

Raw TeX source:

```tex
Let $\hat{g}:\C^3\rightarrow \C^3$ be defined by
$g(z_0,z_1,z_2)=(z_0,z_1,3z_2)$. Since $\hat{g}$ is linear, $\hat{g}$ decends to a map $\CP^2\rightarrow \CP^2$.
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item Find the fixed points of $g$.
%------------------------------------------------------------------*
\item Compute the local Lefschetz number of each fixed point.
%------------------------------------------------------------------*
\item Use this to compute the Euler characteristic of $\CP^2$.
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
```
