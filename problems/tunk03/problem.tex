Let $\sim $ be an equivalence relation on a topological space $X$.
The set of equivalence classes form the quotient space
$X/\mathord{\sim }$ when endowed with the following topology:
$U\subset X/\mathord{\sim }$ is an open set if and only if
$\pi^{-1}(U)$ is open, where $\pi:X\rightarrow X/\mathord{\sim }$ is
the projection taking $x$ to its equivalence class.  The relation
$\sim $ is \emph{open} if $\pi$ is an open map. Suppose that $\sim $
is an open equivalence relation. Show that $R=\{(x,y)\pipe x\sim y\}$
is a closed subset of the space $X\times X$ if and only if
$X/\mathord{\sim }$ is Hausdorff.
