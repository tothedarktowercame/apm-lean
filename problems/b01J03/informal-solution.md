# APM b01J03: A self-normalizing Sylow p-subgroup forces the Galois group to be cyclic of order p

## Why It's Hard

The hypothesis $P=N$ (the Sylow $p$-subgroup is its own normalizer) is strong but
abstract, and the goal $P=G$ is a *field-theoretic* collapse in disguise: it says the
splitting field is already generated by a single root. The path runs group theory →
counting → field theory → back to group theory. The delicate step is a global
**count of order-$p$ elements** (part b) that, combined with the coprimality
$p\nmid s$, forces *every* index-$p$ subgroup $H_\alpha=\mathrm{Gal}(K/F[\alpha])$ to
equal one and the same set — the elements of order $\neq p$. That rigidity is what
makes all the fields $F[\alpha]$ coincide and the splitting field collapse.

## The Key Insight

- $G$ acts faithfully and transitively on the $p$ roots, so $G\hookrightarrow S_p$
  with $p\mid|G|$; since $v_p(p!)=1$, we get $|G|=ps$ with $p\nmid s$, and
  $|P|=p$.
- $P=N$ makes the number of Sylow $p$-subgroups $n_p=[G:N]=s$. Order-$p$ subgroups
  meet trivially, so the order-$p$ elements number exactly $s(p-1)$ — leaving exactly
  $s$ elements of order $\neq p$.
- $H_\alpha$ has order $s$ and (as $p\nmid s$) contains **no** element of order $p$;
  but there are only $s$ such elements in all of $G$, so $H_\alpha$ **is** that fixed
  $s$-element set — the same for every root $\alpha$. Equal subgroups give equal fixed
  fields $F[\alpha]=F[\beta]$, hence $K=F[\alpha]$, $[K:F]=p$, $|G|=p$, $P=G$.

## Complete Proof

Since $f$ is separable and $K$ is its splitting field over $F$, $K/F$ is **Galois**,
and $G=\mathrm{Gal}(K/F)$ acts on the set $\Omega$ of the $p$ distinct roots of $f$.
Because $K$ is generated over $F$ by these roots, the action is **faithful**
($G\hookrightarrow \mathrm{Sym}(\Omega)\cong S_p$); because $f$ is **irreducible**, the
action is **transitive**.

### (a) $|G|=ps$ with $p\nmid s$

Transitivity on the $p$-element set $\Omega$ gives, by orbit–stabilizer, $p=|\Omega|
\mid |G|$, so $p\mid|G|$. On the other hand $G\hookrightarrow S_p$ gives $|G|\mid
p!$. Now $p$ is prime, so among $1,2,\dots,p$ only $p$ itself is divisible by $p$;
hence $v_p(p!)=1$, i.e. $p^2\nmid p!$. Therefore $p\mid|G|$ but $p^2\nmid|G|$, which
is exactly $|G|=ps$ with $p\nmid s$. In particular a Sylow $p$-subgroup $P$ has order
$p$. $\quad\checkmark$

### (b) There are exactly $s(p-1)$ elements of order $p$

By Sylow's theorem the number of Sylow $p$-subgroups is $n_p=[G:N_G(P)]=[G:N]$. The
hypothesis $P=N$ gives
$$
n_p=[G:P]=\frac{ps}{p}=s .
$$
Each Sylow $p$-subgroup has prime order $p$, hence is cyclic with exactly $p-1$
elements of order $p$ (everything but the identity). Two distinct subgroups of order
$p$ intersect in a subgroup whose order divides $p$; it cannot be all of $p$ (else they
are equal), so the intersection is trivial. Moreover every element $g$ of order $p$
generates a subgroup $\langle g\rangle$ of order $p$, which is a full Sylow
$p$-subgroup (the $p$-part of $|G|$ is $p$), so $g$ lies in exactly one Sylow
$p$-subgroup. Hence the order-$p$ elements are partitioned among the $s$ Sylow
subgroups, $p-1$ in each, with no overlaps:
$$
\#\{g\in G : \mathrm{ord}(g)=p\} = s\,(p-1). \quad\checkmark
$$
Consequently the number of elements of order $\neq p$ is
$$
|G| - s(p-1) = ps - s(p-1) = s. \tag{$\ast$}
$$

### (c) $H_\alpha=H_\beta$ and $F[\alpha]=F[\beta]$

Let $\alpha$ be a root of $f$. Then $f$ is the minimal polynomial of $\alpha$ over $F$
(monic, irreducible, $f(\alpha)=0$), so $[F[\alpha]:F]=\deg f=p$. By the Galois
correspondence ($K/F$ Galois) $H_\alpha=\mathrm{Gal}(K/F[\alpha])$ satisfies
$$
|H_\alpha| = \frac{|G|}{[F[\alpha]:F]} = \frac{ps}{p} = s .
$$
Since $|H_\alpha|=s$ and $p\nmid s$, Lagrange forbids any element of order $p$ in
$H_\alpha$: every non-identity element of $H_\alpha$ has order dividing $s$, hence
order $\neq p$. Thus
$$
H_\alpha \subseteq E := \{g\in G : \mathrm{ord}(g)\neq p\}.
$$
By $(\ast)$, $|E|=s=|H_\alpha|$, so $H_\alpha = E$. The right-hand side $E$ does not
depend on the chosen root, so for any other root $\beta$ we likewise get $H_\beta=E$.
Therefore
$$
H_\alpha = E = H_\beta .
$$
Equal subgroups have equal fixed fields under the Galois correspondence, so
$F[\alpha]=K^{H_\alpha}=K^{H_\beta}=F[\beta]$. $\quad\checkmark$

*(Caveat lector: $E$ being equal to the subgroup $H_\alpha$ shows, as a byproduct, that
$E$ is itself a subgroup — the unique subgroup of order $s$, which all the $H_\alpha$
share. We did not need this in advance; it falls out of the count.)*

### (d) $K=F[\alpha]$, and hence $P=G$

Fix a root $\alpha$. By part (c), for **every** root $\beta$ of $f$ we have
$F[\beta]=F[\alpha]$; in particular $\beta\in F[\beta]=F[\alpha]$. So $F[\alpha]$
contains every root of $f$. Since $K$ is generated over $F$ by the roots and
$F\subseteq F[\alpha]\subseteq K$, this forces
$$
K=F[\alpha].
$$
Then $[K:F]=[F[\alpha]:F]=p$, so $|G|=[K:F]=p$ (as $K/F$ is Galois). Comparing with
$|G|=ps$ gives $s=1$. Finally $|P|=p=|G|$, and $P\le G$, so
$$
P=G. \qquad\blacksquare
$$

### Remark

The engine is the exact count in (b): $p\nmid s$ separates $G$ into $s(p-1)$ elements
"of $p$-type" and exactly $s$ elements "of $s$-type," and an order-$s$ subgroup must be
precisely the latter set — a $p$-complement that is *forced to be unique* by the
self-normalizing hypothesis (which is what pinned $n_p=s$). Uniqueness of that
complement is exactly what makes every $H_\alpha$ coincide, collapsing all the
$F[\alpha]$ together. (Indeed $s=1$ in the end, so the whole situation degenerates to
$G=P\cong\mathbb{Z}/p$ acting as a single $p$-cycle on the roots — e.g. $f=x^p-c$ type
behavior — but one only learns $s=1$ *after* running the field-theoretic collapse.)
