## Problem Statement

Raw TeX source:

```tex
Let $X\subset Y$ be smooth, compact oriented manifolds without
boundary. Suppose that there is a smooth function $f:Y\rightarrow X$
with $f|_X=\id_X$. Prove that the inclusion map $\iota:X\rightarrow Y$
is not homotopic to a constant map.
```
