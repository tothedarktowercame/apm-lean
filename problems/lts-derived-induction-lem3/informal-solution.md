# Informal solution

A Borel (G)-spectrum is a spectrum equipped with a (G)-action; equivalently
it is an object of the functor category \(\operatorname{Fun}(BG,\mathrm{Sp})\).
Limits, colimits, and equivalences in a functor category are computed
objectwise. Since (BG) has one object, evaluation at that object is precisely
restriction to the trivial subgroup
\[
\operatorname{Res}_e^G:\operatorname{Fun}(BG,\mathrm{Sp})\to\mathrm{Sp}.
\]

If a (G)-equivariant map is an equivalence after forgetting the action, its
underlying inverse is automatically equivariant: from (uf=fv), compose with
the inverse on both sides to obtain (fu=vg) for the inverse (g). Thus the
inverse lives in the functor category. Hence evaluation, and therefore
\(\operatorname{Res}_e^G\), reflects equivalences. This is specific to the
Borel category; it is not a claim that underlying spectra detect genuine
equivalences in every model of genuine equivariant spectra.
