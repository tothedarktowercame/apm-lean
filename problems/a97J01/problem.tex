Let $f:\R\rightarrow \R$ be a Lebesgue measurable function. Assume
there exists a positive constant $c$ with the property that if
$A\subset \R$ is a bounded Lebesgue measurable set and $f$ is bounded
on $A$ then $|\int_Af(x)dm(x)|\leq c$, where $m$ denotes Lebesgue
measure. Prove that $f$ is Lebesgue measurable.
