## Problem Statement

Raw TeX source:

```tex
Let $f:[0,1]\rightarrow \R$. Let
$V(f)=\sup\{\sum_{i=1}|f(t_i)-f(t_{i-1})|\pipe n\in \N,
0=t_0<t_1<\ldots < t_n \leq 1 \}$. Prove that $f$ is absolutely
continuous if and only if there is a sequence $(f_n)_{n=1}^{\infty}$
of Lipschitz functions on $[0,1]$ with $\lim_{n\rightarrow
\infty}V(f_n-f)=0$.
```
