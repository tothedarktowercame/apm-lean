## Problem Statement

Raw TeX source:

```tex
Consider the functional $\Phi(x,y,y')=\int_{a}^{b}F(x,y(x),y'(x))dx$.
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item State the Euler-Lagrange equations for this functional.
%------------------------------------------------------------------*
\item If $F=F(y,y')$ only, prove that the Euler-Lagrange equations
reduce to $\dbyd{x}(F-y'F_{y'})=0$.
%------------------------------------------------------------------*
\item Among all continuous curves $y(x)$ joining the points $(0,1)$
and $(1,\cosh(1))$, find the one which generates the minimum area when
rotated about the $x$-axis. Recall that this area is
$$A=2\pi\int_{0}^1y\sqrt{1+(y')^2}dx.$$ Hint: $\int
\frac{dt}{\sqrt{t^2-C^2}}=\ln (t+\sqrt{t-C^2})$.
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
```
