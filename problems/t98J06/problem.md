# t98J06

## Bundle Overview

This directory is the canonical APM problem bundle for this problem.

## Problem Statement

Raw TeX source:

```tex
Let $f:X\rightarrow X$ be a smooth map of the orientable $n$-manifold
$X$. Let $F:X\rightarrow X\times X$ be the map $F(x)=(x,f(x))$. Show
that if $F$ is transverse to the diagonal in $X\times X$ then for any
fixed point $p$ of $f$, $df_p-I$ is non-singular on $T_p(x)$ where $I$
denotes the identity homomorphism. Moreover show that orientation
number at the intersection $(p,p)$ is $+1$ if $df_p-I$ preserves
orientation and $-1$ otherwise.
```
