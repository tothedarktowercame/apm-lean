Informal proof

**Why it's hard:** The problem statement appears to have a typo — both branches define f_n(t) = 1, but it's clear from context that f_n is the n-th Rademacher function: +1 on odd dyadic intervals and -1 on even dyadic intervals. The challenge is that f ∈ L^∞ is much weaker than continuous; we can't directly use uniform approximation, and pointwise convergence of f_n fails (Rademacher functions don't converge a.e.).

**The key insight:** The Rademacher functions f_n converge weakly to 0 in L²([0,1]) (and in fact weak-*) — they are essentially an orthonormal-like sequence. For any indicator of a dyadic interval [k/2^m, (k+1)/2^m), and any n > m, the integral ∫ f_n · 1_{[k/2^m,(k+1)/2^m)} = 0 because the Rademacher function f_n averages to zero over each refining dyadic subinterval. By density of dyadic step functions in L¹, this extends to all of L¹, hence to f ∈ L^∞ ⊂ L¹ on the finite-measure space [0,1].

**Proof:**

Interpret f_n as the n-th Rademacher function: f_n(t) = (-1)^{k+1} for t ∈ [(k-1)/2^n, k/2^n), with f_n(1) = -1. So f_n is +1 on odd-indexed half-open dyadic intervals and -1 on even-indexed ones.

**Step 1: ∫_0^1 f_n = 0 for n ≥ 1.** Each dyadic interval [(k-1)/2^n, k/2^n) has measure 1/2^n, and there are equally many odd-k and even-k intervals (2^{n-1} each), so the integrals cancel.

**Step 2: ∫_0^1 1_J · f_n = 0 for n large enough, where J = [j/2^m, (j+1)/2^m).** When n > m, the interval J is exactly the union of 2^{n-m} consecutive dyadic intervals at level n. Half of these (2^{n-m-1}) have odd k and half have even k (since k ranges over a block of consecutive integers of length 2^{n-m} ≥ 2). The +1 contributions cancel the -1 contributions, giving ∫_J f_n = 0.

**Step 3: For any dyadic step function s = Σ c_j 1_{J_j} where each J_j is a dyadic interval at level m, ∫ s · f_n = 0 for all n > m.**

This follows by linearity from Step 2.

**Step 4: Approximate f ∈ L^∞ by dyadic step functions in L¹.**

Since [0,1] has finite measure, f ∈ L^∞([0,1]) ⊂ L¹([0,1]). The dyadic step functions are dense in L¹([0,1]): given ε > 0, there exists a continuous function φ on [0,1] with ‖f - φ‖_1 < ε/2 (continuous functions are dense in L¹). Since φ is uniformly continuous on [0,1], we can find a dyadic step function s at some level m with ‖φ - s‖_∞ < ε/2, hence ‖φ - s‖_1 < ε/2. Therefore ‖f - s‖_1 < ε.

**Step 5: Conclude.** For n > m:

$$\left|\int_0^1 f \cdot f_n\right| = \left|\int_0^1 (f - s) f_n + \int_0^1 s \cdot f_n\right| = \left|\int_0^1 (f - s) f_n\right| \leq \|f - s\|_1 \cdot \|f_n\|_\infty \leq \varepsilon \cdot 1 = \varepsilon$$

since |f_n| = 1 a.e. So lim sup_n |∫ f f_n| ≤ ε. Since ε > 0 was arbitrary, lim ∫ f f_n = 0. ∎

**What connects:** This is the prototypical weak convergence result: Rademacher functions are the simplest example of an L²-orthonormal sequence that converges weakly but not strongly to 0. The argument is the standard "vanish on dense subspace + uniform bound ⇒ vanish everywhere" — a special case of the Banach-Steinhaus / weak convergence principle. The Riemann-Lebesgue lemma (∫ f cos(nx) → 0 for f ∈ L¹) is the same theorem with the trigonometric system replacing the Rademacher system. More abstractly, this is a manifestation of the fact that any uniformly bounded sequence in L^∞ that's weakly null on dyadic indicators is weakly null on all of L¹.
