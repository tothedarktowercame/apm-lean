## Problem Statement

Raw TeX source:

```tex
Consider the first-order differential equation $u'(t)+u(t)=\cos(u(t))$,
posed as an initial value problem for $t>0$ with the initial
condition $u(0)=u_0$.
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item Use the contraction mapping theorem to show that there is 
exactly one solution $u$ to this initial value problem for each $u_0$
in $\R$.
%------------------------------------------------------------------*
\item Prove that $\exists \xi\in \R:\forall u_0\in \R:$
$\lim_{t\rightarrow \infty}u(t)=\xi$ where $u$ is a solution to the
boundary value problem corresponding to $u_0$.
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
```
