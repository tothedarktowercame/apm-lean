# lts-monadic-integration

## Bundle Overview

This stem is bundled for corpus completeness but belongs to a different
series from the APM problems.

## Problem Statement

Raw TeX source:

```tex
Let $X$ be a Banach space with enough Pettis integrals. Then $X$ is an $\mathbb{M}$-algebra when we endow $X$ with the weak sigma-algebra, the norm bornology, and the algebra structure map $c\colon \mathbb{M}X \to X$ given by $c(\mu) = \int \mathrm{id}_X \, d\mu$.
```
