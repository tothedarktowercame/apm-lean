For every nonzero $\epsilon\in \R$, define a bounded linear operator
$D_{\epsilon}:L^2(\R)\rightarrow L^2(\R)$ by setting
$D_{\epsilon}f(x)=(f(x+\epsilon-f(x-\epsilon)))/2\epsilon$.  Given an
arbitrary function $f\in L^2(\R)$, show that as $\epsilon$ tends to
zero,$\exp(D_{\epsilon})f$ converges to $Tf$ in $L^2(\R)$, where
$Tf(x)=f(x+1)$. Hint: use the Fourier transform.
