# Prelim defect

The problem as printed, for every ε > 0, is false in two ways.

Existence fails. For f = 0 and ε = 2 a decaying solution satisfies (u')² = u² - (2ε/3)u³ on its orbit, which at u = 1 is 1 - 4/3 < 0, so u(0) = 1 is impossible.

Unrestricted uniqueness fails even for small ε. For f = 0 and 0 < ε < 3/2, the orbit (u')² = u² - (2ε/3)u³ is a homoclinic loop through 0 with maximum 3/(2ε) > 1. It passes u = 1 twice, and starting from either passage it decays to 0 as x → ∞, giving two solutions.

What it was trying to say, since the problem asks for the contraction mapping principle, is that for ε small relative to a bound on f there is a solution, unique in a ball. The registered statement says exactly that.
