## Problem Statement

Raw TeX source:

```tex
Set up and apply the contraction mapping principle to show that the
following boundary value problem has a unique
solution: $-u_{xx}+u-\epsilon u^2 = f(x)$ for $x\in (0,\infty)$ such
that $u(0)=1$ and $u(\infty)=0$ with $\epsilon>0$ and $f(x)$ a smooth
compactly supported function on $(0,\infty)$
```
