State Cauchy's integral theorem expressing the value of an analytic
function at a point as a contour integral. Let $f$ be an analytic
function defined in the whole complex plane. Prove that
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item if $f$ is bounded, then it is constant;

\end{alist}
