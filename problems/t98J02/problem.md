# t98J02

## Bundle Overview

This directory is the canonical APM problem bundle for this problem.

## Problem Statement

Raw TeX source is preserved verbatim in `problem.tex`:

```tex
Let $F$ be a closed surface. Let $p:\tilde{F}\rightarrow F$ be a
finite covering. Let $C$ be a simple closed curve in $F$ and
$\tilde{C}$ a lift of $C$ to $\tilde{F}$ (\ie\ $p|_{\tilde{C}}$ is a
homeomorphism). Prove or find a counterexample to the following:
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item If $C$ in non-separating then so is $\tilde{C}$.
%------------------------------------------------------------------*
\item If $C$ is separating then so is $\tilde{C}$. 
%------------------------------------------------------------------*
\end{alist}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
```
