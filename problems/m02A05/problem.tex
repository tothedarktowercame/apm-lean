Consider the functional $J[x,y]=\int_{0}^{\pi/2}[ (x'(t))^2 +
(y'(t))^2+2x(t)y(t)]dt$ and the boundary conditions $x(0)=y(0)=0$ and
$x(\pi/2)=y(\pi/2)=1$. 
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\begin{alist}
%------------------------------------------------------------------*
\item Find the Euler-Lagrange equations for the functional.
%------------------------------------------------------------------*
\item Find all extremals.
%------------------------------------------------------------------*
\item Find a global minimum if it exists, or show it doesn't exist.
%------------------------------------------------------------------*
\item Find a global maximum if it exists, or show it doesn't exist.
%------------------------------------------------------------------*
\end{alist}
