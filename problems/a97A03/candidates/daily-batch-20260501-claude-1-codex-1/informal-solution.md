Informal proof

**Why it's hard:** The forward direction (Lipschitz ⇒ a.e. bounded derivative) requires the Rademacher-type fact that a Lipschitz function is a.e. differentiable with derivative bounded by the Lipschitz constant. The reverse direction (a.e. bounded derivative ⇒ Lipschitz) requires absolute continuity to convert the pointwise a.e. bound into a global Lipschitz bound via the Fundamental Theorem of Calculus for Lebesgue integrals — without absolute continuity this fails (e.g., the Cantor function has derivative 0 a.e. but is not Lipschitz).

**The key insight:** Absolute continuity is exactly the bridge that makes f(y) - f(x) = ∫_x^y f'(t) dt valid. Once you have this representation, both directions are immediate from monotonicity of the integral and the L^∞ bound.

**Proof:**

Recall that absolute continuity of f on [a,b] implies f is differentiable a.e., f' ∈ L¹([a,b]), and the Fundamental Theorem of Calculus holds:
$$f(y) - f(x) = \int_x^y f'(t)\,dt \quad \text{for all } x, y \in [a,b].$$

**(Lipschitz ⇒ a.e. bounded derivative).** Suppose |f(x) - f(y)| ≤ B|x - y| for all x, y ∈ [a,b]. At any point x ∈ [a,b] where f is differentiable:
$$|f'(x)| = \left|\lim_{y \to x} \frac{f(y) - f(x)}{y - x}\right| \leq \limsup_{y \to x} \frac{|f(y) - f(x)|}{|y - x|} \leq B$$

Since f is absolutely continuous, it's differentiable a.e., so |f'(x)| ≤ B for a.e. x ∈ [a,b]. Taking C = B works.

**(a.e. bounded derivative ⇒ Lipschitz).** Suppose f is absolutely continuous and |f'(x)| ≤ C for a.e. x ∈ [a,b]. For any x, y ∈ [a,b] with x ≤ y:
$$|f(y) - f(x)| = \left|\int_x^y f'(t)\,dt\right| \leq \int_x^y |f'(t)|\,dt \leq \int_x^y C\,dt = C(y - x) = C|y - x|$$

The first equality uses the FTC (valid because f is absolutely continuous), the first inequality is the triangle inequality for integrals, and the second uses the a.e. bound (the set where |f'| > C has measure zero, so it doesn't contribute to the integral). Taking B = C works.

The case x > y follows by symmetry, and x = y is trivial. ∎

**What connects:** This problem highlights the central role of absolute continuity in real analysis: it is precisely the regularity needed to make the FTC work for Lebesgue integrals. The equivalence Lipschitz ⇔ AC + bounded derivative is the integrated version of the basic mean value theorem from elementary calculus, lifted to the Lebesgue setting. Without AC, the Cantor function provides a counterexample: it has f' = 0 a.e. (so any C > 0 bounds the a.e. derivative), but it's not even Lipschitz (it goes from 0 to 1 on intervals of arbitrarily small total measure). The result also gives the standard characterization Lip([a,b]) = W^{1,∞}([a,b]) — the Sobolev space with bounded weak derivative.
