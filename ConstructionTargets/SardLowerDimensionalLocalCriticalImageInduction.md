# Lower-dimensional local critical-image induction application

This module packages the first explicit source-dimension induction application in the local Sard route.

For a strictly lower-dimensional parameter space, a local Sard hypothesis for every sufficiently smooth map applies to the composite of the original map with a local parameterization. Local smoothness supplies the differentiability needed by the parameterized critical-image transfer, so the composite's restricted critical-image nullity yields nullity of the localized original critical image.

The downstream argument must instantiate this theorem with each exact restricted scalarized-jet kernel parameterization, aggregate the resulting local nullity over the refined first-nonzero-jet loci, and combine those loci with the Taylor-flat and first-derivative rank cases.
