# Second-countable local nullity aggregation

This module aggregates pointwise local image-nullity over a source set in a
second-countable space.

Each point is assigned an open neighborhood containing it whose intersection
with the source set has null image. Hereditary Lindelöfness extracts a
countable subcover, after which countable null-union aggregation proves that
the whole source image is null.

The downstream Sard argument must provide these local hypotheses from the
kernel-chart source-dimension induction and then combine the nonzero-jet
strata with the Taylor-flat locus.
