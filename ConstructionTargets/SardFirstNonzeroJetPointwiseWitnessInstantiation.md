# First-nonzero-jet pointwise witness instantiation

This module turns the scalarized open-chart package into the pointwise local-nullity witness used by the refined-locus argument.

At a point of a first-nonzero successor-jet locus, global smoothness constructs the exact scalarized implicit chart and supplies the original map's local `ContDiffAt` hypothesis. The open kernel-coordinate regularity package supplies the parameter map's local smoothness, while strict finrank decrease instantiates the lower-dimensional Sard hypothesis. The result is an open source neighborhood containing the point whose restricted refined-locus image is null.

Second-countable local aggregation can now promote these pointwise witnesses to nullity of the whole refined locus.
