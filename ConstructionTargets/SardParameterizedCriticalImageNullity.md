# Parameterized local critical-image nullity

This module packages the induction-application step for a parameterized local
critical set.

If a localized set of critical points of `f` lies in the image of a smooth
parameterization, then criticality transport places its parameter preimages in
the critical set of the composite. Nullity of the full critical image of that
composite therefore transfers to the original localized image.

The remaining Sard argument must supply the composite's null critical image
from source-dimension induction and aggregate the resulting localized
nonzero-jet strata with the Taylor-flat locus.
