# First-nonzero-jet open regularity data

This module promotes the exact scalarized implicit chart attached to a nonzero successor jet from base-point regularity to an open parameter neighborhood.

Along with the selected directions, scalar functional, defining fields, base point, and strict kernel finrank decrease, the theorem retains an open right-coordinate neighborhood containing the base coordinate. On that neighborhood, the exact inverse-chart kernel parameter is `ContDiffAt` at the requested finite nonzero order and `DifferentiableAt` at every point.

This is the regularity package consumed by the pointwise refined-locus local-nullity witness before second-countable aggregation.
