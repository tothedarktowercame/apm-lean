# Finite-order projected inherited measure package

`exists_projected_inherited_borel_addHaar_data` packages the derivative range
and orthogonal residual with Borel-space instances, residual nontriviality, and
additive-Haar measures while preserving the measurable spaces inherited from
the ambient finite-dimensional target.

The package can therefore be destructured directly in the finite-order
positive-rank pointwise nullity proof without introducing incompatible
measurable-space instances.
