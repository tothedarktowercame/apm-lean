# Implicit-function restricted-slice image containment

`ImplicitFunctionData.image_inter_sourceRestrict_subset_image_comp_kernelParameter`
turns fixed-coordinate level-set membership into the exact image containment
needed by the local projected-slice nullity witness.

After restricting to the implicit-function chart source and an arbitrary open
right-coordinate neighborhood, every point of the level set is represented by
the inverse chart with its left coordinate fixed at the base value.  Applying
an arbitrary target map preserves this parameterized image containment.
