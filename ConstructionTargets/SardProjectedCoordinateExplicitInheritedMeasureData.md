# Projected-coordinate explicit inherited measure data

`exists_projectedCoordinates_explicit_inherited_measureData` packages Borel
proofs, measures, and additive-Haar instances for the derivative range and its
orthogonal residual with every measurable-space parameter explicitly fixed to
the inherited subtype instance.

This lets the positive-rank pointwise nullity adapter install one coherent
coordinate-measure environment without asking typeclass synthesis to choose
new measurable spaces at the generic witness boundary.
