# Derivative-range coordinate topology package

`range_orthogonal_topology_package` supplies `ProperSpace` and
`SecondCountableTopology` certificates for a continuous linear map's range and
its orthogonal complement in a finite-dimensional real inner-product target.

Finite-dimensional properness also provides the `LocallyCompactSpace`
instances required by compact projected-chart nullity, so both coordinate
spaces meet the wrapper's topological hypotheses after local installation.
