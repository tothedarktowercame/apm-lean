# Projected-chart target-fiber slice containment

`targetFiber_subset_inverseChartSlice` identifies the source representation
needed for every target-coordinate fiber of a set contained in a product chart.

When the chart first coordinate agrees with the target map's first coordinate,
the residual coordinate of each fixed-coordinate target-image fiber lies in
the image of the corresponding inverse-chart slice. The result is purely
set-theoretic and requires no measurable-space choices.
