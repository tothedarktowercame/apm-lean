# Parameterized-image nullity transfer

This module records the image transport used after applying Sard induction on
a lower-dimensional parameter space.

Images commute exactly with parameterized source images. Consequently, if the
image of a composite map on a parameter set is null, then the original map has
null image on every source set contained in the parameterized image. The
result is stated for an arbitrary target measure and requires no unnecessary
measurability hypotheses.

The downstream argument must instantiate this transfer for each exact kernel
parameterization and aggregate the resulting local nonzero-jet nullity with the
Taylor-flat locus.
