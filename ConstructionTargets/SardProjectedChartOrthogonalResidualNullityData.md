# Projected-chart orthogonal-residual nullity data

`orthogonalResidual_inverseSlice_nullity_data` combines zero derivatives of
all orthogonal-residual inverse slices with two-sided chart regularity. It
returns the paired pointwise `C¹` regularity and zero-derivative certificates
used by compact projected-chart fiber nullity.

The final projection is the identity continuous linear map on the orthogonal
residual coordinate, so no extra loss occurs between the concrete chart slice
and the compact-nullity interface.
