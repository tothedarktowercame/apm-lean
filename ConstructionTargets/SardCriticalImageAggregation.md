# Countable aggregation of null critical images

`criticalImage_null_of_countable_local_null` isolates the countable-union step
in a manifold Sard argument.  Given a countable set of patch centers covering
an abstract critical set, and nullity of the image of the critical set
restricted to every patch, it proves that the full critical image is null for
the same target measure.

The statement deliberately does not mention charts, differentiability, or a
particular definition of criticality.  Those data determine the set and prove
the local hypotheses; this theorem only aggregates them.  In particular, it
does not prove rectangular local-set Morse--Sard or begin the chart assembly
inside a frozen consumer.
