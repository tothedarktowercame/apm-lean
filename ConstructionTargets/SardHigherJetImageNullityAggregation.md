# Higher-jet image-nullity aggregation

This module combines the reviewed higher-jet locus decomposition with null-union aggregation.

If the image of the locus flat through order `k` is null and each nonzero-jet locus for orders in `Icc 1 k` has null image, then the whole localized source image is null.

The downstream Sard argument must provide flat-locus nullity from Taylor covering and nonzero-jet nullity from the kernel-chart source-dimension induction.
