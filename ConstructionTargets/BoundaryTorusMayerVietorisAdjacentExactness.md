# Boundary-torus adjacent Mayer--Vietoris exactness

This target transports the production exactness segments adjacent to the
piece term into the compiled integral coordinates.  The union segment has
the actual production reassembly arrow followed by the production connecting
map in overlap coordinates.  The intersection segment has that same
connecting map followed literally by `intSignedFold`.

The intersection exactness and the compiled universal kernel of
`intSignedFold` imply that the canonical lift of the connecting map to that
kernel is epic.  Composing with `integerSignedFoldKernelIso` gives an epic map
from the boundary-torus homology object to `ℤ`.  This conclusion uses only
exactness; it does not identify the connecting map with a chosen coordinate
map, construct a section, split an extension, or assert a torus homology
table.

The exact residual is monicity (or an inverse) for the kernel-coordinate map.
Exactness supplies epimorphy only.  Proving monicity requires information from
the preceding Mayer--Vietoris term (in the relevant degree, vanishing of the
image of reassembly), after which a short exact sequence and a derived
splitting can be considered.
