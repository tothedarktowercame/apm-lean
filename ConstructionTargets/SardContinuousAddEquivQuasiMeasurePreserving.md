# Continuous additive equivalences preserve Haar null sets

`ContinuousAddEquiv.quasiMeasurePreserving_addHaar` proves that a continuous
additive equivalence is quasi-measure-preserving between additive Haar
measures when its target is locally compact and second countable.

The mapped source measure is again an additive Haar measure.  Haar uniqueness
then makes it absolutely continuous with respect to the chosen target Haar
measure, which is precisely the measure-theoretic condition required to pull
null coordinate images back through a target-coordinate equivalence.
