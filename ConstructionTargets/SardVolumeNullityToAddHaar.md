# Volume-nullity to additive-Haar nullity

`addHaar_eq_zero_of_volume_eq_zero` transfers nullity from the canonical
finite-dimensional volume measure to an arbitrary additive Haar measure on the
same real inner-product space. It uses uniqueness of additive Haar measures up
to scalar multiplication; evaluating that equality on a volume-null set makes
the arbitrary Haar measure vanish there as well.

This lets the localized Taylor-flat theorem, which is stated using `volume`,
feed the finite-jet assembly theorem without restricting its arbitrary target
additive Haar measure.
