# Finite-order rank-zero order-one endpoint nullity

At Taylor order one, exact endpoint equality reduces to equality of the target and source finranks. `ContinuousLinearEquiv.ofFinrankEq` therefore constructs the target-to-source coordinate equivalence required by the equal-dimensional rank-zero endpoint theorem.

The resulting specialization proves additive-Haar nullity of the rank-zero image without requiring an externally supplied equivalence. This completes the order-one branch of the endpoint classification; the genuinely one-dimensional-target branch remains.
