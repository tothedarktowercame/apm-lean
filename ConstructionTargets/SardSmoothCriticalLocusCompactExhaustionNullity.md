# Smooth critical-locus compact exhaustion nullity

This module identifies the nonsurjective-derivative locus of a smooth map with
the closed locus where derivative rank is at most `finrank F - 1`. It exhausts
that locus by countably many compact sets and aggregates image nullity supplied
for each compact piece.

The result isolates the remaining Sard induction work in one hypothesis:
compact subsets of the critical locus have null image.
