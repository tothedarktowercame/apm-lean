# Projected positive-rank dimension data

`projected_positiveRank_dimension_data` derives the source and target ambient
rank bounds from an exact derivative rank. When that rank is positive, it also
proves strict dimension drop for the kernel of the range-projected derivative,
which is the source space of the lower-dimensional slice.

This packet supplies the arithmetic fields needed by the positive-rank branch
of the finite-order pointwise nullity construction. Rank zero remains assigned
to the flat/Taylor branch.
