# Finite-order projected-coordinate measure data

`exists_projected_coordinate_measure_data` supplies compatible Borel
measurable structures and additive-Haar measures on a derivative range and its
orthogonal residual. Nonsurjectivity additionally gives the nontrivial residual
space required by projected-slice nullity.

The package is intended to be destructured without changing measurable-space
instances inside the finite-order positive-rank pointwise composition.
