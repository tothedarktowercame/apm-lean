# Independently indexed projected-slice fiber nullity

`forall_fiber_image_null_of_subset_projectedSlices_indexed` corrects the fiber
interface by separating the fixed-coordinate index type from the ambient
source type used in the Sard dimension inequality.

For every coordinate value, containment in a lower-dimensional projected
slice image combines with the induction hypothesis, smoothness, dimension
drop, surjective projection, and zero projected derivatives to prove nullity
of the corresponding residual fiber image.
