# Chart-coordinate dimension-drop nullity

This target combines the canonical Euclidean strict-finrank image-nullity
theorem with an explicit target chart.  The main theorem proves that `g '' s`
is null in a chosen chart when its coordinate expression is a differentiable
map `f : E → F` with `finrank E < finrank F`.

The measure is an explicit additive Haar measure on `F`.  No measure is put on
the manifold.  The file also retains two bounded operations from the earlier
experimental survey: countable unions inside one fixed chart and transport
through an explicitly supplied differentiable overlap map.

This is not a global range-null theorem.  Passing from these local statements
to a manifold result still requires a proved countable chart cover, exact
decomposition of the range into chart patches, and compatible coordinate
changes.  Those interfaces are not supplied here, and no Sard,
nonsurjectivity, or canonical manifold-measure conclusion is claimed.
