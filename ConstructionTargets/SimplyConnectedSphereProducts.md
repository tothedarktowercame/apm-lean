# Simply connected sphere products

This target supplies two reusable facts needed by `t95J04`:

- simple connectivity is closed under arbitrary topological products, proved
  coordinatewise using path projections and `Path.Homotopic.prod`;
- the unit sphere in `EuclideanSpace ℝ (Fin (n + 1))` is simply connected for
  `2 ≤ n`, via the explicit first-coordinate pole and the open-cover sphere
  theorem.

The target is universe-polymorphic in the product factors and contains no
dimension-specific primary API.
