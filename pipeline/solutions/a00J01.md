# a00J01 — $L^p$ Norms Converge to $L^\infty$ Norm

## Setup

**What the problem is asking.** On the finite measure space $([0,1], \mathcal{L}, m)$, we have two ways to measure the "size" of a bounded measurable function: the $L^p$ norms $\|f\|_p = \left(\int_0^1 |f|^p\,dm\right)^{1/p}$ and the $L^\infty$ norm. The problem asks us to define the latter and show that the former converge to it as $p \to \infty$.

**Background: Essential supremum.** Why not just use $\sup|f|$? Because $L^p$ spaces identify functions that agree a.e., so we need a notion of "supremum" that ignores null sets. The essential supremum does exactly this.

**Definition.** The $L^\infty$ norm of $f$ is:

$$\|f\|_\infty = \inf\!\big\{M \geq 0 : m(\{x \in [0,1] : |f(x)| > M\}) = 0\big\}$$

Equivalently, $\|f\|_\infty$ is the smallest value $M$ such that $|f| \leq M$ almost everywhere. This is called the **essential supremum** of $|f|$.

**Why finite measure matters.** On $[0,1]$, $m([0,1]) = 1 < \infty$, so $L^\infty \subset L^p$ for every $p \geq 1$. This guarantees every $\|f\|_p$ is finite and the limit question makes sense. On $\mathbb{R}$ with Lebesgue measure, the constant function $f = 1$ is in $L^\infty$ but not in any $L^p$.

## Key Insight

The proof is a **squeeze**. The upper bound is easy: since $|f| \leq \|f\|_\infty$ a.e., you just integrate and take $p$-th roots. The lower bound is the real content: pick any level $\alpha$ slightly below $\|f\|_\infty$. By definition of essential supremum, the set where $|f| > \alpha$ has *strictly positive* measure. Integrating $|f|^p$ over just that set gives you at least $\alpha^p \cdot m(E)$, and the factor $m(E)^{1/p} \to 1$.

## Proof

Write $L = \|f\|_\infty$.

**Upper bound ($\limsup \leq L$).** Since $|f(x)| \leq L$ for a.e. $x$:

$$\|f\|_p = \left(\int_0^1 |f|^p\,dm\right)^{1/p} \leq \left(\int_0^1 L^p\,dm\right)^{1/p} = L \cdot m([0,1])^{1/p} = L.$$

Therefore $\|f\|_p \leq L$ for all $p \geq 1$, so $\displaystyle\limsup_{p\to\infty} \|f\|_p \leq L$.

**Lower bound ($\liminf \geq L$).** Fix $\varepsilon > 0$ and set $\alpha = L - \varepsilon$. Define

$$E_\varepsilon = \{x \in [0,1] : |f(x)| > \alpha\}.$$

Since $\alpha < L = \|f\|_\infty$, the value $\alpha$ is *not* an essential bound for $|f|$, so by definition of the infimum: $m(E_\varepsilon) > 0$. Now restrict the integral to $E_\varepsilon$:

$$\|f\|_p = \left(\int_0^1 |f|^p\,dm\right)^{1/p} \geq \left(\int_{E_\varepsilon} |f|^p\,dm\right)^{1/p} \geq \left(\int_{E_\varepsilon} \alpha^p\,dm\right)^{1/p} = \alpha \cdot m(E_\varepsilon)^{1/p}.$$

Since $m(E_\varepsilon) > 0$, we have $m(E_\varepsilon)^{1/p} = e^{(\ln m(E_\varepsilon))/p} \to e^0 = 1$ as $p \to \infty$. Therefore:

$$\liminf_{p\to\infty} \|f\|_p \geq \alpha = L - \varepsilon.$$

Since $\varepsilon > 0$ was arbitrary, $\displaystyle\liminf_{p\to\infty} \|f\|_p \geq L$.

**Conclusion.** Combining both bounds:

$$L \leq \liminf_{p\to\infty}\|f\|_p \leq \limsup_{p\to\infty}\|f\|_p \leq L,$$

so $\displaystyle\lim_{p\to\infty} \|f\|_p = \|f\|_\infty$. $\blacksquare$

## Where You'd Get Stuck

**1. "Why can't I just use $\sup|f|$?"** The essential supremum can be strictly less than the pointwise supremum (e.g., modify $f$ on a single point). The definition via infimum over essential bounds is the whole point — make sure you *state* it, since the problem explicitly asks you to.

**2. The lower bound is where most students struggle.** The tempting wrong move is to try to bound $\|f\|_p$ below using the *full* integral. That doesn't help — you need to isolate a set of positive measure where $|f|$ is large. The $\varepsilon$-room trick (taking $\alpha = L - \varepsilon$ strictly less than $L$) is essential; at $\alpha = L$ the set $\{|f| > L\}$ could have measure zero.

**3. Forgetting that $m(E_\varepsilon)^{1/p} \to 1$ requires $m(E_\varepsilon) > 0$.** If $m(E_\varepsilon) = 0$ then $0^{1/p} = 0$ for all $p$ and the bound is trivial (gives you $\geq 0$). The entire argument collapses. This is exactly why you need $\alpha$ strictly below $L$: to guarantee the set has positive measure.

**4. The finite-measure hypothesis is load-bearing.** The upper bound uses $m([0,1])^{1/p} = 1$. On an infinite measure space, this factor blows up and the inequality $\|f\|_p \leq \|f\|_\infty$ can fail (again, $f \equiv 1$ on $\mathbb{R}$). The result still holds on $\sigma$-finite spaces with the right hypotheses, but the clean statement requires finite measure.

**5. Dead end: trying Hölder or interpolation.** Some students reach for $\|f\|_p \leq \|f\|_q^{q/p}\|f\|_\infty^{1-q/p}$ (interpolation). This gives the upper bound but makes the lower bound harder to extract. The direct approach above is cleaner and what graders expect.
