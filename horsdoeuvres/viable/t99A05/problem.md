# t99A05

## Bundle Overview

This directory is the canonical APM problem bundle for this problem.

## Problem Statement

Raw TeX source:

```tex
Let $f:X\rightarrow Y$ be a smooth map between manifolds, and let
$Z\subset X$ be a submanifold with $\dim Z = \dim Y$ and $\deg (f|Z)
\mod 2 \neq 0$. Must there be a compact submanifold $W\subset X$ whose
mod $2$ intersection number $I_2(W,Z)$ is nonzero? Why?
```
