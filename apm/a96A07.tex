Suppose that the function $g$ is analytic in an open set containing
the closure of the unit disk $\Delta=\{z\pipe |z|<1\}$ and that $g$
is one-to-one on the unit circle $\Gamma=\partial \Delta$. Show that
$g$ must map $\Delta$ in a one-to-one fashion onto the bounded domain
$D$ whose boundary is $C=g(\Gamma)$.
